| 中断位置 | 原 PID → 恢复 PID | 结果 |

| 下载中 | 4588 → 4594 | 复用分片断点，首个已完成分片未重复请求 |
| 校验后、计划尚未交给执行器 | 4600 → 4607 | 复用下载包，重新校验，不重新下载 |
| 文件写入中 | 4614 → 4622 | 保留已完成文件，接续其余文件 |

四个场景均验证：

- 200 个文件内容哈希全部一致。
