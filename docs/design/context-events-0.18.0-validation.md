# 上下文事件本地验证记录

日期：2026-11-16。分支：`release/0.18.0`。

## 已实现

- 九类来源发布 `context.updated`，包括通用 data 的直接写入、gateway 写入、分片提交和 OSS 导入完成。
- 有界分段日志、重启回放、游标查询、SSE、鉴权隔离及凭证撤销检查。
- 事件只带来源、提交计数与资源 ID；私有事件定向 Egress，共享事件不广播。
- 日志失败不回滚数据，部分写入报告已提交部分；新增对象与 blob 内容复用、幂等回执分别处理。

## 验证结果

- 全仓库 `go test -race ./...` 通过。最后的日程计数、录音内容比较、日志查询索引和 daemon 容错调整，分别重跑了受影响包的竞态测试。
- `go vet ./...` 通过，`go build ./cmd/yc` 对应的 CLI 构建成功。
- 日志测试覆盖并发追加、重启回放、过滤后游标前进、大小/时间清理、尾部截断恢复、中段损坏重置、写入失败。
- daemon 测试覆盖九类来源、重复通知/快照、清空日程、健康多日部分成功、SSE 历史与实时衔接、凭证撤销、跨客户端隔离。
- data 测试覆盖新对象复用 blob、幂等重试、分片未完成/完成/重复 commit、OSS 导入完成及重启恢复。
- 后台测试覆盖图片元数据与文件完成通知、录音转写成功及部分结果写入失败。
- 通过本地模拟 Relay 的真实 WebSocket 往返验证 standalone 写入响应和定向事件；通过真实 HTTP 回调验证 proxied 的认证、事件体与先记录后投递。
- 使用编译后的 CLI，在独立临时 `YOOOCLAW_HOME` 启动真实 direct daemon：SSE 事件到达后读取对象内容成功；重复幂等写入保持 1 条事件；复用 blob 新增对象后增为 2 条；重启后两条事件可回放且 eventId 保持不变。测试进程已退出，不影响用户当前 profile。

## 验收边界

这份记录证明本地实现、自动化测试和隔离 daemon 行为。没有连接生产手机、OpenClaw 或 Thread 实例做消费端验收，也没有执行正式版本发布。

数据文件与事件日志不在同一事务中；提交后、记事件前崩溃仍可能漏事件。消费者首次接入、游标过期及周期性对账时需要重新读取当前数据。具体协议和恢复规则见 [接口文档](../context-events.md)。
